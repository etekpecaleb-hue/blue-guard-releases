# Blue Guard downloads

**Blue Guard** is a system health and security scanner by **Kaliv Digitals**.

## Download

Get **BlueGuard.exe** from the latest release:
https://github.com/etekpecaleb-hue/blue-guard-releases/releases/latest

Double-click it to run. No installation and no Python needed (Windows 10 or 11).
For the full set of checks, accept the offer to restart as Administrator.

The first time, Windows SmartScreen may show "Windows protected your PC". Click **More info**, then **Run anyway**.

## Updates

Blue Guard checks this page when it starts. If there's a newer version, it asks before downloading it,
checks its SHA-256 fingerprint against the one published here, then switches to it.
Only the version file is requested; nothing about your computer is sent.
